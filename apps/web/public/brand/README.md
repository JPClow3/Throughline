# Throughline brand kit

The live product uses the **Inkline** system (see `/DESIGN.md` and `colors/colors.md`): warm paper, ink borders, hard offset shadows. No glass, blur, or translucency.

- `colors/` — Inkline token exports for design handoff.
- `svg/throughline-mark-single-ink.svg` / `throughline-mark-single-white.svg` / `throughline-wordmark.svg` — preferred marks.
- `svg/throughline-icon-liquid-glass.svg` and `throughline-mark-gradient.svg` — historical archive assets from the pre-Inkline glass direction; do not use in product UI.
